Shopify product CSV broken by quotes in titles

A product title like 24" Monitor or an HTML description with quotes can shift a Shopify CSV into the wrong columns. Repair it in your browser without uploading the file.

Product exports and hand-made product sheets often contain inch marks and quotes: 24" Monitor, 1/2" drill bit, or HTML like <p>"Fast IPS" panel</p>. In a CSV file a double quote has a special meaning. If a quote inside a field is not written as two quotes (""), most importers read it as the start or end of a field, and the rest of the row slides into the wrong columns.

What it looks like

The title ends up in the description column, prices show up as text, or the import reports the wrong number of columns on some rows. Often only the rows with a quote in them are affected, which makes it easy to miss.

Fixing it by hand

For a few rows you can open the file in a text editor and double every quote that sits inside a field: 24"" Gaming Monitor, then wrap that field in quotes. For hundreds of rows that is slow and easy to get wrong, which is what the tool below is for.

What the tool does

It reads the file, works out which quotes are field boundaries and which are part of the text, doubles the ones that are text, and gives you a clean CSV back. Changed cells are counted so you can check them. It does not change prices, SKUs or anything without a quote in it.

Check the result in a spreadsheet before importing. Quote repair is a best guess: a field that is ambiguous on its own (for example a quote right before a comma) may need a manual look.
