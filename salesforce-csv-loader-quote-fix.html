Clean a CSV before a Salesforce or CRM import

Unescaped quotes, garbled characters and uneven columns are common reasons a CRM import rejects rows. Repair the file in your browser first, without uploading it.

CRM import tools, Salesforce's Data Loader and Data Import Wizard among them, expect a well-formed CSV: one header row, the same number of columns on every row, and quotes written the standard way. Exports from spreadsheets, older systems or quick scripts often break one of those rules.

Things that commonly go wrong

  • A note or company name with an unescaped quote in it shifts the rest of the row.
  • Accented names arrive garbled (MÃ¼ller instead of Müller) because the file was saved or opened with the wrong encoding.
  • Some rows have fewer columns than the header.

What the tool does

It repairs the quotes, converts misread UTF-8 back to the right characters, pads short rows to the header's column count, and gives you a clean CSV. It does not know your CRM's field rules (required fields, picklist values, date formats), so those still need checking against the import template.

Because the file stays in your browser, you can clean customer data without sending it to another service first.
