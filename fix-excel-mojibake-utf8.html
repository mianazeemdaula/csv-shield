Stopping it in Excel

If the file itself is fine and only Excel shows it wrong, import it instead of double-clicking it: Data, From Text/CSV, and choose UTF-8 as the file origin. Saving the file with a UTF-8 byte order mark (BOM) at the start also makes Excel read it as UTF-8. The tool below can add one when you download.

When the garbage is already in the file

If someone saved the file after it was misread, the broken characters are now real text and need converting back. The tool finds runs of characters that look like misread UTF-8, turns them back into their original bytes and decodes those properly.
